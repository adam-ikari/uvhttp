UVHTTP 路线图 ​

愿景 ​

UVHTTP 是 C 语言 HTTP 服务器库，为生产级网络应用提供标准。

  • HTTP/1.1 服务器 (23,226 RPS)
  • WebSocket 全双工通信
  • 零拷贝文件传输
  • LRU 缓存预热
  • TLS 1.3 (mbedtls)
  • 32 位嵌入式系统
  • 完整文档
  • Python 配置工具
  • 输入验证和安全加固
  • 错误处理

技术栈演进 ​

当前技术栈 ​

  • 核心: C99、libuv、llhttp
  • TLS: mbedtls
  • 内存: mimalloc（可选）
  • 哈希: xxHash
  • JSON: cJSON（可选）
  • 测试: Google Test

未来考虑 ​

  • TLS: BoringSSL、LibreSSL
  • 哈希: FarmHash、MetroHash
  • 内存: jemalloc、tcmalloc
  • 异步: io_uring（Linux）、kqueue（BSD）
  • 压缩: zstd、brotli
