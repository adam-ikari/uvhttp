为什么选 UVHTTP（对比其他轻量 C HTTP 库） ​

大多数轻量 C HTTP 库只优化峰值 RPS 便止步。UVHTTP 优化的是会击垮生产的属性：内存安全。一个能在 10 秒基准测试中存活下来的每连接泄漏或 use-after-free，会在一周内让嵌入式设备 OOM。UVHTTP 是轻量、可嵌入、支持 32 位的 C 库，并在每夜 CI 中以 ASan 与 UBSan 双重验证，证明这类 bug 已根除。
