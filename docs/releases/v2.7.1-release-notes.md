# UVHTTP v2.7.1 Release Notes

**Release Date**: 2026-08-26
**Version**: 2.7.1
**Type**: Patch Release (Quality & Embedding)

## Overview

UVHTTP v2.7.1 is a **quality-focused patch release** that fixes the ci-fuzz CI pipeline (broken for 5 consecutive days), makes embedding via `add_subdirectory` work out of the box, and introduces the **performance regression gate** to prevent silent performance degradation.

## 🛠 Key Changes

### 1. ci-fuzz CI 修复 (PR #364)

**Problem**: ci-fuzz 连续失败 5 天（2026-08-20 ~ 08-24）。ci-fuzz 是唯一用 clang 编译的工作流，项目默认 C99 + `-Werror`，clang 在 C99 下对同 TU 内重复 typedef 报 `-Wtypedef-redefinition`（GCC 不报，所以主 CI 一直绿）。

**Fix**:
- `CMAKE_C_STANDARD` 99 → 11（与 PHILOSOPHY.md "实际构建使用 C11" 对齐）
- 删除未使用的 `uvhttp_validate_buffer_state`（clang `-Wunused-function` 报错）
- fuzz_router 链接补齐 `libminiz.a` / `libxxhash.a`
- 移除引用已不存在 API 的过时 `fuzz_request` harness

**Verification**: fuzz_router 5s 跑 442K execs, 0 crash, 0 timeout

### 2. 嵌入构建修复 (PR #365)

**Problem**: uvhttp public headers 包含 `llhttp.h`、`<uv.h>`、`xxhash.h`、`uthash.h`、mbedtls 头文件，但这些依赖在 CMake 中被标记为 `PRIVATE`，嵌入者通过 `add_subdirectory` 集成时找不到头文件。

**Fix**:
- `libuv`/`xxhash`/`llhttp`/`mbedtls` 从 `PRIVATE` → `PUBLIC` 链接
- PUBLIC include dirs 添加 `deps/uthash/src`（uthash 为 header-only 库）

**Verification**: 嵌入测试项目 add_subdirectory 构建成功，服务器启动/停止正常

### 3. 性能回归门禁 (PR #366)

新增 `scripts/performance/regression_check.py`：
- CI 基准测试后自动对比内置基线（`/` 83K, `/json` 81K, `/large` 5.7K RPS）
- 阈值 10%，RPS 低于基线 90% 则 CI 失败
- 仅在 PR 和 pre-release push 时触发，`workflow_dispatch` 不阻塞（开发期手动基准）

**Verification**: PASS 场景 exit=0，FAIL 场景（70K RPS）exit=1 正确报错
