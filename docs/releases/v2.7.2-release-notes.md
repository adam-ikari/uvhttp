# UVHTTP v2.7.2 Release Notes

**Release Date**: 2026-09-07
**Version**: 2.7.2
**Type**: Patch Release (Bug Fix)

## Overview

UVHTTP v2.7.2 is a **bug-fix patch release** that resolves **34 code-review defects** found during a full code audit. The fixes split into two groups: **13 P0/P1 critical defects** (memory safety, RFC 6455 compliance, routing correctness, connection accounting) and **21 P2/P3 improvements** (TLS robustness, conditional-request correctness, static-file race conditions, config surface). All 101 tests pass; no API changes, fully backward compatible.

## 🛠 Key Changes

### 1. P0/P1 — 13 项关键缺陷修复 (commit a3bc755)

- **query string 路由匹配**: parameterized routes now strip the query string before matching — `/users/1?tab=2` no longer mismatches
- **MAX_PARAMS 栈溢出边界**: parameter extraction is bounded at `MAX_PARAMS`; no more out-of-bounds writes
- **on_url/on_header_field 跨 chunk 分段累积**: parser callbacks correctly accumulate data split across chunk boundaries
- **migrate_to_trie 失败悬垂指针**: fixed dangling pointer on the trie-migration failure path
- **WS 非 TLS send 短写截帧**: WebSocket non-TLS path re-sends on short writes instead of truncating the frame
- **CLOSE 后继续处理帧（RFC 6455）**: no longer processes data frames after a CLOSE frame (RFC 6455 compliance)
- **If-Modified-Since 时区错误**: `mktime` → `timegm` — comparisons now use UTC, eliminating local-timezone offset
- **accept 失败 active_connections 下溢**: `uv_accept` failure no longer underflows the connection counter (permanent-503 issue resolved)
- **connection_new 失败路径 UAF**: fixed use-after-free on the connection-creation failure path
- **server_free 不排空在途 close 回调**: drain in-flight close callbacks before freeing, avoiding libuv access to freed memory
- **超时路径 WS wrapper 泄漏**: WebSocket wrapper no longer leaks on the timeout path
- **TLS send 忙等降限**: non-blocking TLS send busy-wait reduced to bounded retries, cutting CPU spinning

### 2. P2/P3 — 21 项改进与修复 (commit a0eae2b)

- **TLS EINTR 重试**: TLS send/recv auto-retry on `EINTR`
- **If-None-Match weak/多值 ETag**: weak comparison and multi-value ETag lists supported
- **目录列表 TOCTOU**: static directory-listing path race fixed
- **on_header_value 分段累积**: header value correctly accumulated across chunks
- **keep-alive headers_extra 泄漏**: keep-alive connection reuse no longer leaks `headers_extra`
- **X-Forwarded-For 默认不信任**: `X-Forwarded-For` now untrusted by default — new `trust_proxy_headers` config toggle
- **MIME 双表合并单表**: static-file MIME tables merged into one, removing lookup inconsistency
- **TLS cipher 满排空**: full cipher list drained properly instead of silent truncation
- **死代码清理**: dead code paths removed
- **listen 参数校验**: `uvhttp_server_listen` validates invalid arguments (port 0 / empty address)
- **server_stop 幂等化**: `uvhttp_server_stop` is safe to call repeatedly
- **If-Modified-Since 支持 3 种 HTTP-date 格式**: RFC 7231 IMF-fixdate / RFC 850 / asctime formats
