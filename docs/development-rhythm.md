# UVHTTP 开发节奏

## 每周周期

| 天 | Sprint | 活动 | 产出 |
|---|--------|------|------|
| 周一 | Sprint 1 | 开发 (6-7h) | 2-4 个 PR |
| 周二 | Sprint 2 | 开发 (6-7h) | 2-4 个 PR |
| 周三 | Sprint 3 | 开发 (6-7h) | 2-4 个 PR |
| 周四 | Sprint 4 | 开发 (6-7h) | 2-4 个 PR |
| 周五 | Sprint 5 | 测试 + 发布 | v2.x.y |

## 每日节奏

```
08:00  检查 daily-build 结果 → 创建/更新 Issue
08:30  规划当日 Sprint → 选择 6-7h 任务
09:00  开始开发
12:00  午休
13:00  继续开发
17:00  提交当日 PR
17:30  Sprint 回顾 → 更新 backlog
```

## AI 开发速度

| 任务类型 | 平均耗时 | 日容量 |
|---------|---------|--------|
| docs | 0.5-1h | 6-12 个 |
| fix | 1-2h | 3-6 个 |
| feat | 1-1.5h | 4-6 个 |
| test | 0.5-1h | 6-12 个 |
| chore | 0.3-0.5h | 12-18 个 |

## 自动化

- **daily-build** (04:00 UTC+8): 构建 + 测试，失败自动创建 Issue
- **nightly** (08:00 UTC+8): 深度测试 + 覆盖率 + ASan + UBSan
- **PR CI**: 每次 PR 自动验证
- **deploy**: 合并 main 自动部署网站
